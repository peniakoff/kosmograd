# Blender sources

Canonical `.blend` files live under `assets/`. `export/` is generated OBJ. Workshop `.nmf` is produced in ModelViewer, not here.

| Path | Purpose |
|---|---|
| `atlas/` | Shared concrete/metal working PNG |
| `scripts/export_wrsr.py` | Apply hygiene + OBJ export (Y-up) |
| `assets/buildings/kosm_*/` | One folder per building |
| `assets/vehicles/kosm_*/` | One folder per vehicle |

Read [docs/BLENDER.md](../docs/BLENDER.md), [docs/BLENDER_MCP.md](../docs/BLENDER_MCP.md), and the matching section of [docs/ASSETS.md](../docs/ASSETS.md) before opening Blender.
